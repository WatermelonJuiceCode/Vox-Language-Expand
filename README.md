# Vox Syntax Highlighting Extension
### This extension is officially published by Vox
### Author: WatermelonCode

Provides syntax highlighting for `.voxs` and `.v` files in Visual Studio Code. Syntax highlighting only, does not support execution.

## Features
- Highlights Vox language keywords (`if`, `else`, `for`, `while`, etc.)
- Highlights function definitions and calls
- Highlights types (`int`, `float`, `string`, `bool`, etc.)
- Highlights single-line and multi-line comments

![Vox syntax highlighting example](https://gitee.com/watermelon-juice-code/vox-syntax-highlighting/raw/master/shili.png)
Doesn't it look a lot like C#?

## Usage
No configuration required. Simply open a `.voxs` or `.v` file and it works out of the box.


# Vox 语法高亮扩展
### 该扩展为 Vox 官方所出
### 作者：WatermelonCode

为 Visual Studio Code 提供对 `.voxs` 和 `.v` 文件的语法高亮。只有语法高亮，不支持运行

## 功能
- 高亮 Vox 语言的关键字（`if`、`else`、`for`、`while`等）
- 高亮函数定义和调用
- 高亮类型（`int`、`float`、`string`、`bool`等）
- 高亮单行或多行注释
